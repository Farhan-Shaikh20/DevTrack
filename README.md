# DevTrack — Client Project Management System

DevTrack is a PHP-based Client Project Management System designed to simplify client, project, task and workflow management from a centralized platform.

## 🚀 Features

* Client management
* Project management
* Task management
* Project status tracking
* Dashboard-based project overview
* Organized client-project workflow
* CRUD operations
* Database-driven application
* Responsive and user-friendly interface

## 🛠️ Tech Stack

* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Development Environment:** XAMPP
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/DevTrack.git
```

2. Move the project into the XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** from XAMPP.

4. Create the required MySQL database.

5. Import the provided SQL database file if included.

6. Configure the database connection according to the local environment.

7. Open the project in your browser:

```text
http://localhost/DevTrack/
```

## 🎯 Purpose

DevTrack was developed as a practical full-stack PHP project to understand backend development, database integration, CRUD operations, authentication/workflows, and real-world project management concepts.
